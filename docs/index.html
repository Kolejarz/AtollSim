Atoll Navigator

This repository contains the Atoll Navigator React component (a sliding-maze puzzle and economy simulator).

To preview the UI locally:

  1. Clone the repository: git clone https://github.com/Kolejarz/AtollSim.git
  2. Install dependencies (if you add a build): npm install
  3. Serve this directory and open docs/index.html in your browser. For a quick preview using npx: npx serve docs or python -m http.server 8000 --directory docs

GitHub Pages publishing is not configured by this PR — enable Pages from the repository settings and point it to the docs/ folder on the default branch to publish this page.

See the README for more information about running the component locally and packaging it into an app.
